# Missing Piece

An independent React/Vite NBA roster analytics app for identifying team weaknesses and evaluating player fit. It has no platform SDK, account, API key, or backend requirement.

## Run locally

```bash
npm install
npm run dev
```

The app ships with a curated 2024–25 team-data snapshot. The **Analyze** action produces a deterministic, data-driven roster assessment locally, so it works in a demo without any AI-service credentials.
